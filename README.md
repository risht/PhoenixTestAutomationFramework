# Phoenix Test Automation Framework

A scalable Java automation framework for UI and API testing, designed around reusable test components and maintainable automation practices.

## Tech Stack

- Java
- Selenium WebDriver
- REST Assured
- TestNG
- Maven
- MySQL / JDBC
- Allure Reporting
- Log4j2
- Apache POI
- CSV / JSON test data

## Key Capabilities

- UI automation with Selenium WebDriver
- REST API automation with REST Assured
- Database validation using MySQL/JDBC
- Data-driven testing
- Reusable utilities and test components
- TestNG execution and listeners
- Allure test reporting
- Structured logging with Log4j2
- Maven-based dependency and test execution

## Framework Focus

The framework demonstrates how UI, API, and database validation can be organized into a reusable automation architecture rather than isolated test scripts.

## Getting Started

### Prerequisites

- Java JDK
- Maven
- Chrome or another supported browser
- Access to any required test environment/database configuration

### Run Tests

```bash
mvn clean test
```
